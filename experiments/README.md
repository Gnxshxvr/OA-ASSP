# Experiments Organization

This directory organizes the experimental records of the OA-ASSP project into distinct frozen authoritative and historical provenance categories.

* **`frozen/`**: Contains the authoritative experiment metadata, configurations, and manifests for `stage20_corrected_20260923_092749`.
* **`historical/`**: Documents the pre-correction baseline run (`stage20_scaleup_48g_20260920_215427`) preserved as immutable historical context.

The benchmark data files reside in `results/` to ensure full compatibility with reproduction scripts.
