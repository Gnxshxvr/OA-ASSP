# Supplementary Materials

This directory contains supplementary resources supporting the OA-ASSP research project:

* **`presentation/`**:
  * `OA_ASSP_DAA_DA1_Presentation.pptx`: Comprehensive 18-slide presentation deck covering the research problem, methodology, mathematical cost model, empirical results, and findings.
  * `create_presentation.py`: Automation script using `python-pptx` that generated the presentation deck.
  * `rendered_presentation_slides/`: Rendered high-resolution image proofs of all presentation slides.

* **`audits/`**:
  * `ADVERSARIAL_AUDIT.md`: In-depth audit report examining potential vulnerabilities, assumptions, and recomputation tests.
  * `P0_FIX_REPORT.md`: Audit report documenting the correction pass and metric standardization.
  * `COST_REGIME_DEFINITION.md`: Formal definitions distinguishing analysis-grade from end-to-end timing regimes.
  * `CROSSOVER_DEFINITION.md`: Mathematical specification of nominal versus genuine crossovers.
  * `PRIOR_ART_POSITIONING.md`: Detailed comparison against existing literature on algorithm selection and shortest-path benchmarking.
